# Welcome to Keli 👋

This is an AI Financial Coach using Expo, Clerk, Neon (Drizzle ORM).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Copy environment variables

   ```bash
   cp .env.example .env
   ```

   Add your Clerk publishable key from the [Clerk Dashboard](https://dashboard.clerk.com).

3. Start the app

   ```bash
   npx expo start
   ```
